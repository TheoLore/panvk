# PanLore

Identity string used in Vulkan `driverName` / `driverInfo`.

## Mesa line

This tree tracks **Mesa 26.3** via upstream branch `staging/26.3`
(currently reported in `VERSION` as `26.3.0-rc1` or later on that branch).

Sync:

```
Actions → Sync Mesa upstream → ref: staging/26.3
```

Then re-run **Apply PanLore identity** (sync replaces the tree).

Reference for Android kbase patch series (pinned Mesa 26.3.0-devel era):
https://github.com/zenithblue-oss/panvk-kbase-android

Maintainer account: TheoLore.
